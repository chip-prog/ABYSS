# 待辦

## 卡框（使用者晚點處理）

- [ ] 秘法、深淵、無名三個陣營的卡框，照嫣紅第二版的版面生成
- [ ] 嫣紅卡框重生一張：名稱布條改成平直、左右對稱、以卡片中線為中心，封蠟只壓在布條左端
- [ ] 卡背照 1：1.5 重新生成（目前 5 張是從 1：1.71 壓扁的，約矮了 12%）

生成規格：

- 綠幕背景（卡圖窗內也填同一個綠），1024 × 1536，不要用 transparent background 這類提示詞
- 版面位置（由上往下）：封蠟 1～14%、名稱布條 1～12%、卡圖窗 13～55%、羊皮紙 57～92%、底部裝飾 93% 以下
- 羊皮紙約佔卡片寬度 85%，淺色乾淨，不偏紅、綠、紫
- 卡圖窗下緣正中要有尖刺或寶石底座（程式會在這裡疊稀有度寶石）
- 裝飾集中在上半部，下半部左右邊框細一點；底部中央裝飾小一點，避免壓到風味文字
- 不要畫任何文字

收到圖後：去背、量位置、文字測試，再放進 assets/frames/ 並在 content.json 的陣營資料加上 frame。
