# ABYSS

Roguelike 卡牌遊戲的底層架構：一個資料驅動的戰鬥引擎、遊戲本體（經典模式・第一章），以及讓沒有程式基礎的人也能編輯內容的 Studio。

## 怎麼開啟

純網頁，不需要安裝或建置。

- **線上**：在 GitHub 儲存庫的 Settings → Pages，把來源設為 `main` 分支的根目錄，之後用 Pages 網址開啟即可。
- **本機**：在這個資料夾執行下面的指令，然後開啟 http://localhost:8000

```bash
python3 -m http.server 8000
```

| 頁面 | 用途 |
|---|---|
| `index.html` | 入口 |
| `game.html` | 遊戲本體，只使用「正式」內容 |
| `game.html?preview=1` | 測試環境：使用 Studio 的工作內容（含草稿） |
| `studio.html` | Studio |

## 內容怎麼流動

1. 共同創作者在 Studio 編輯。修改只存在自己的瀏覽器裡，新增的項目預設是「草稿」。
2. 用試玩沙盒或「完整試玩一輪」確認。
3. 在「匯入／匯出」匯出內容包（.zip，含內容檔與上傳的圖片），交給負責審核的人。
4. 審核者在自己的 Studio「合併匯入」（匯入的項目會標成草稿），確認後切成「正式」。
5. 匯出內容包並解壓，把裡面的 `content` 與 `assets` 兩個資料夾上傳到儲存庫根目錄。遊戲只會顯示「正式」的項目。

## 資料夾

```
content/content.json   所有遊戲內容（卡片、角色、敵人、遭遇、遺物、狀態、陣營、規則）
assets/                圖片檔（卡圖、肖像、紙偶姿勢），內容檔裡只記檔名
js/engine/             引擎，純邏輯、不碰畫面
  schema.js            積木定義：效果、條件、時機、關鍵字（Studio 表單由此自動產生）
  battle.js            戰鬥規則與每種效果積木的實作
  describe.js          由積木自動產生卡片說明文字
  validate.js          防呆檢查
  run.js               一輪冒險的流程（連戰、獎勵、篝火、頭目）
js/ui/                 遊戲與 Studio 共用的畫面
  battle-view.js       戰鬥畫面與演出（出手特寫、受擊）
  puppet.js            紙偶：翻面換姿勢、低影格動作
  store.js             Studio 的瀏覽器儲存空間（工作內容與圖片）
  zip.js               內容包的壓縮與解壓
js/game.js             遊戲本體
js/studio.js           Studio
tests/engine.test.mjs  引擎自動測試
```

## 卡框與卡背

每個陣營可在 Studio 的「陣營」頁上傳一張卡框和一張卡背；「規則」頁另有一張共用卡背，給沒有自己卡背的陣營使用。卡框是比例 1：1.5 的去背 PNG，卡圖窗挖空透明、不畫任何文字。名稱、費用、說明、稀有度寶石都由程式疊在卡框上，位置可在「陣營」頁微調。沒有卡框的陣營會使用預設的簡易卡面。

## 戰鬥場景

戰鬥發生在教堂後殿的舞台上，後牆是一幅祭壇三聯畫：三片畫板各有外框、中間留縫，兩翼繞著鉸鏈開闔，戰鬥開始時打開、勝利時闔上。畫板會依外框開口的形狀自動裁切（上傳外框時自動找出開口）。分成四層：教堂遠景、三聯畫、舞台地板、光效。教堂遠景、舞台地板、三聯畫外框在 Studio「規則」頁上傳，所有場景共用；三聯畫的中央板與兩翼（正面、背面）在「場景」頁上傳，可在「規則」頁設定各階段預設用哪一組，或在「遭遇」頁個別指定。沒有素材的層會顯示暗色的暫代圖樣。

每個場景可以調整三聯畫的位置、大小、兩翼角度與亮度，每片畫板可調裁切；也可以放任意數量的「場景零件」（去背剪紙），選擇放在三聯畫後、紙偶後或紙偶前，並設定位置、大小、角度與動態（搖晃、浮動、旋轉、漂移、顫抖、閃爍）。角色站位、地板高度、教堂亮度在「規則」頁調整。

Studio 上傳需要去背的圖（紙偶、卡框、零件、圖示、地板、前景）時，四角是綠色的圖會自動去除綠幕。

狀態、遺物、陣營也可以上傳圖示（各自的頁面）。

## 紙偶姿勢

角色與敵人在 Studio 各有一組姿勢欄位，上傳去背圖即可，主角面向右、敵人面向左。缺少的姿勢會改用待機圖；完全沒有圖時顯示暫代的紙牌。引擎會依打出的牌與發生的事件自動選姿勢，不需要逐張卡設定。

| 主角 | 敵人 |
|---|---|
| 待機、攻擊、格擋、技能、祝福、受擊（無扣血）、受擊（有扣血）、獻祭、倒下 | 待機、攻擊、蓄力、受擊（無扣血）、受擊（有扣血） |

## 哪些事不用寫程式

新卡片、角色、敵人與招式、遭遇、遺物、狀態、陣營、初始牌組、關卡流程、所有數值，都在 Studio 裡用現有積木完成。

## 哪些事需要改程式

只有「全新的積木」：一種引擎還不認得的效果、條件或時機。步驟是在 `schema.js` 加上定義，在 `battle.js` 的 `EFFECTS` 加上實作，在 `describe.js` 加上說明文字。加完之後 Studio 會自動出現對應的選項。

## 測試

```bash
node tests/engine.test.mjs
```
